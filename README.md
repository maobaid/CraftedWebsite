# متجر كرافتد — Crafted eCommerce (Arabic RTL)

متجر إلكتروني حديث بالكامل باللغة العربية بتصميم من اليمين لليسار (RTL).

## التشغيل

```bash
npm install
npm start
```

ثم افتح [http://localhost:4200](http://localhost:4200).

## لوحة الإدارة

- **المسار:** `/admin`
- **تسجيل الدخول:** `/admin/login`
- **بيانات الدخول (للتطوير):**
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin123`

## المميزات

### واجهة العملاء (عربي RTL)
- **الرئيسية:** عرض المنتجات في شبكة مع ترتيب حسب السعر، حركات hover وتكبير خفيف على الصور، زر "أضف إلى السلة".
- **سلة المشتريات:** قائمة المنتجات، تعديل الكمية، حذف، المجموع الفرعي والإجمالي، زر "إتمام الطلب".
- **إتمام الطلب (متعدد الخطوات):**
  1. **التحقق من رقم الهاتف:** إدخال الرقم، إرسال OTP، إدخال رمز التحقق (لا يمكن المتابعة بدون التحقق).
  2. **معلومات العميل:** الاسم، البريد (اختياري)، العنوان (إجباري للطلب الأول). إذا كان العميل مسجلاً مسبقاً تُعبأ البيانات تلقائياً.
  3. **خيار التوصيل:** جدولة التاريخ والوقت (اختياري). عند عدم الاختيار تظهر الرسالة: "سيتم توصيل طلبك خلال يومي عمل" (قابلة للتعديل من لوحة الإدارة).
  4. **مراجعة الطلب:** ملخص المنتجات والإجمالي، كود الخصم، زر "تأكيد الطلب".
- **صفحة نجاح الطلب** بعد التأكيد.

### لوحة الإدارة (عربي)
- **تسجيل الدخول** آمن (جلسة).
- **إدارة المنتجات:** إضافة، تعديل، حذف، رفع/ربط صور، السعر، خصم (نسبة أو مبلغ ثابت)، تفعيل/إيقاف.
- **إدارة الخصومات:** إنشاء كود خصم، تاريخ انتهاء، عدد مرات الاستخدام.
- **إدارة العملاء:** عرض العملاء، عدد الطلبات، تعديل البيانات، بحث.
- **إدارة الطلبات:** عرض الطلبات، فلترة (قيد الانتظار، تم التأكيد، تم الشحن، تم التوصيل)، تحديث حالة الطلب، عرض موعد التوصيل وحالة الدفع.
- **إعدادات التوصيل:** تعديل رسالة "سيتم التوصيل خلال يومي عمل" وقواعد التوصيل.

## البيانات والتكامل

- **حالياً:** التطبيق يعمل بدون خادم باستخدام `localStorage` لحفظ المنتجات والطلبات والعملاء ورمز الإدارة. مناسب للتطوير والعروض.
- **OTP:** خدمة `OtpService` جاهزة: في التطوير تقبل أي رمز ٦ أرقام للأرقام المنتهية بـ `00` (مثلاً `0500000000`). لربط Twilio أو Supabase Auth قم بتعديل `src/app/core/services/otp.service.ts`.
- **قاعدة البيانات:** يمكن لاحقاً استبدال التخزين المحلي بـ Supabase أو Firebase أو PostgreSQL عبر تقديم خدمات جديدة تستبدل الاستدعاءات الحالية في `ProductService`, `OrderService`, `DiscountService`, `DeliverySettingsService`.

## البنية

- **Angular 19** مع مكونات standalone.
- **RTL** عبر `dir="rtl"` و`lang="ar"` في `index.html`.
- المسارات والحراس (مثل `adminGuard`) لتنظيم الوصول.
